# Kubernetes Applications

## Purpose

Deploy Kubernetes platform applications and add-ons.

## Resources Created

Examples include:

- External Secrets Operator
- NGINX Ingress Controller
- Cert Manager
- Fluent Bit
- ArgoCD
- Monitoring Components

## Deployment

```bash
terraform init
terraform plan
terraform apply
```

## Dependencies

- EKS Cluster
- kubectl Access
- Helm Access
